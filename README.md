# AI Quest — Interactive AI Quiz Game (DSC401-6, Units I & II)

72 questions · 21 topic tags · 7 formats · timer, lifelines, adaptive difficulty, leaderboard.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Deploy (Streamlit Community Cloud)
1. Push this folder to a public GitHub repo (app.py at the root).
2. share.streamlit.io → New app → pick the repo, main file `app.py` → Deploy.
Note: leaderboard.csv lives on the server and resets when the app restarts/sleeps.

## Files
- app.py — the game
- question_bank.json — questions (generated by build_bank.py)
- build_bank.py — source of the question bank + integrity checks
- verify_search.py — computes every search/state-space answer
- test_app.py, test_life.py — automated tests (Streamlit AppTest)
